# Packages

This directory will contain independently installable Gen1Recomp mod packages.

## Planned package IDs

| Package | Required | Responsibility |
|---|---:|---|
| `kanto_rework_core` | Yes | Tokens, profiles, adaptive layout, input, focus, components, adapter registry |
| `kanto_rework_ui` | Yes | Native presenters, dialogue, modals, menu and screen rework |
| `kanto_rework_companion` | No | Movable overlay, widgets, editor, favorites, registered items |
| `kanto_rework_battle` | No | Classic/3D battle UI, information panels, battle QoL |
| `kanto_rework_system` | No | Save slots, loading, native map/PC access, system shortcuts |
| `kanto_rework_moves` | No | Learned-move library and persistent stored PP |
| `kanto_rework_quests` | No | Quest data, journal, progression, map integration |
| `kanto_rework_compat` | No | Versioned adapters for third-party mods |

Package directories will be created during the technical spike when their minimum manifests and test contracts are defined. Empty placeholder mods are deliberately avoided.
